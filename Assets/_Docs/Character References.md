# Организация референсов персонажей на Google Диске

Корневая папка: https://drive.google.com/drive/folders/1d1KooR4He1W5DggTR2spO-VXElYHL4AP

Для каждого персонажа используется структура «Персонаж / Актуальные» и «Персонаж / Исходники». В «Актуальные» лежат выбранный общий референс и доступные отдельные виды, в «Исходники» — сохранённые предшествующие скетчи. Пометка «А-поза» используется только у соответствующих изображений; недостающие ракурсы не создавались при организации. Пустая папка исходников означает, что отдельная предыдущая версия не найдена.
